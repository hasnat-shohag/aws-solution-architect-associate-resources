এই লেসনে জানবেন কীভাবে অনেক tenant কে একসাথে serve করা যায় এবং API কে route, protect ও monitor করা যায়।

## Isolation models

- **Silo:** প্রতি tenant আলাদা resource stack। ব্যয়বহুল কিন্তু নিরাপদ।
- **Pool:** একসাথে বহু tenant একই resource stack ব্যবহার করে। cost কম কিন্তু isolation কম।
- **Bridge:** কিছু data শেয়ার হয়, কিন্তু critical operations আলাদা।
- Tenant isolation প্রায়ই matching app layer, data layer, IAM এবং network isolation এর সময় ভাবতে হয়।

## API management

- API Gateway `/products/v1` এবং `/v2` রাউটিং could handle version routing and versioning.
- API Gateway REST API can be used independently while HTTP API is lighter or cheaper lower.
- ALB path based routing এবং NLB high throughput level এ কাজ করে।
- API Gateway API Gateway API Gateway API Gateway versioning request validation rate limiting caching monitoring traffic management।
- API Gateway request validation authorization and response mapping এর জন্য ভালো।
