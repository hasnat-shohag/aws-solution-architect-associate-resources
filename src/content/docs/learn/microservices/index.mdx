মাইক্রোসার্ভিসেস হলো একটি **ডিজাইন পদ্ধতি** — বড় monolithic অ্যাপটাকে ছোট ছোট, স্বাধীন সার্ভিসে ভাগ করা, যেন প্রতিটি সার্ভিস নিজেই scale, deploy, update হতে পারে। এই থিম AWS-এর অফিসিয়াল ওয়াইটপেপারের ৪১ পাতা ধাপে ধাপে ২০টি লেসনে বাংলায় সাজায় — প্রতি লেসনে কীওয়ার্ড টেবিল, SAA পরীক্ষার টিপ আর ডায়াগ্রাম।

SAA পরীক্ষায় মাইক্রোসার্ভিসেস সরাসরি "ডোমেইন" না হলেও **Design, Resilience, Cost Optimization, Security** — প্রায় প্রতিটি ডোমেইনে এর ধারণা আসে (Lambda vs EKS vs Fargate, per-service database, event-driven, caching, observability ইত্যাদি)।

## এই থিমে যা আসে

- মাইক্রোসার্ভিসেস আর্কিটেকচারের কম্পোনেন্ট: UI, API, compute (Lambda/ECS/EKS/Fargate), datastore
- সার্ভারলেস ডিপ্লয়মেন্ট: SAM, CloudFormation, Lambda Layers, SnapStart
- Resilience: DR (RTO/RPO), HA (multi-AZ)
- Distributed systems: service discovery, distributed data (Saga, event sourcing, CQRS)
- Config & secrets, cost optimization (Spot, Graviton)
- Communication: REST, GraphQL, gRPC, async messaging (SQS/SNS/EventBridge/MQ/MSK/Kinesis)
- Orchestration: Step Functions, state management
- Observability: CloudWatch, logs, X-Ray tracing, log analysis
- Auditing: CloudTrail, Config rules, change management
