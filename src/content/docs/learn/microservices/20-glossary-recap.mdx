## Review conclusion

Microservices scaling, development speed ও organizational growth সহজ করে, কিন্তু একে সব ক্ষেত্রের সমাধান ভাবা যাবে না। সিদ্ধান্তের আগে দেখুন: architectural complexity, operational demand, observability, security ও change management। Containers, serverless বা দুটির ভাগসাম্য ব্যবহার করে AWS managed services complexity কমাতে সাহায্য করে।

## Document back matter

- **Contributors:** ডকুমেন্টে AWS Solutions Architecture দল ও অন্য contributives এর নাম রয়েছে। এখানে প্রশ্ন হতে পারে না; এটি source documentation হিসেবে মনে রাখা ভাল।
- **Document history:** সার্বিক তালিকায় সংস্করণ/তারিখ দেখা যায়, যেমন ইতিমধ্যে ২০১৯, ২০২৩, ও ২০২৬-এর আপডেট। তাই পুরোনো উৎস পড়লে বর্তমান service name গুলো আলাদা করতে হবে।
- **Notices:** Amazon-এর trademark policy ও মূল English translation disclaimer মনে রাখুন। অনুবাদ গ্রাহকের ভাষায় সঠিক না হতে পারে—স্টাডি পরিকল্পনার কারণে মূল API, service ও architecture-এর নাম মূল source-এর সাথে যাচাই করুন।
- **AWS Glossary:** whitepaper শেষে “AWS Glossary” section এ এই নামগুলোর মানে আবার পাওয়া যায়: API, Application Load Balancer, Auto Scaling, Amazon CloudWatch, Amazon ECS, Amazon EKS, AWS Fargate, AWS Lambda, Amazon VPC, AWS PrivateLink, Amazon RDS, DynamoDB, AWS App Mesh, Amazon S3, Amazon ElastiCache, AWS IoT, Amazon ElastiCache।
